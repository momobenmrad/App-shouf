# Flownova — script voix off (darija)

Durée 70 s. Voix actuelle : ElevenLabs « wajdi klai » (eleven_v4), `public/audio/flownova/voice.mp3` ; le minutage vient de sa transcription mot à mot.
À faire relire par une personne tunisienne. Pour la remplacer (ta propre voix par exemple), enregistre en suivant ce minutage puis :

```
python3 audio/make_audio_flownova.py
npx remotion render FlownovaExplainer out/flownova-explainer.mp4 --codec=h264 --crf=18
```
